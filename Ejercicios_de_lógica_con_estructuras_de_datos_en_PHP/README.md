# Ejercicios de Lógica con Estructuras de Datos en PHP

Este repositorio contiene la **Actividad - Módulo 4 - Ejercicios de lógica con estructuras de datos en PHP**.  
La actividad incluye **4 ejercicios** desarrollados en PHP aplicando arreglos, ciclos y funciones.

---

## 📋 Ejercicios

1. **Problema de Lista Invertida**  
   Programa que toma un array de números y devuelve una nueva lista con los elementos en orden inverso.

2. **Problema de Suma de Números Pares**  
   Script que recorre un array de números enteros y suma todos los números pares.

3. **Problema de Frecuencia de Caracteres**  
   Función que recibe una cadena de texto y devuelve un array asociativo con la frecuencia de cada carácter.

4. **Problema de Bucle Anidado (Pirámide de Asteriscos)**  
   Programa que utiliza bucles anidados para imprimir un patrón de asteriscos en forma de pirámide.
