# Modulo 3 - Actividad 5
### Ejercicios de logica con estructuras de datos en PHP

Este repositorio contiene tres algoritmos de ordenamiento implementados en PHP:
 
1. **Bubble Sort** → Ordena una lista de numeros de forma descendente.
2. **Merge Sort** → Ordena una lista de palabras alfabeticamente.
3. **Insertion Sort** → Ordena una lista de nombres alfabeticamente.

### Ejecucion
Desde la terminal, ejecuta cada archivo con:
```bash
php bubble_sort.php
php merge_sort.php
php insertion_sort.php
