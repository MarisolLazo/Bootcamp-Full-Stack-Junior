📚 Bibliotech Halloween 🎃
Objetivo

Sistema web para gestionar libros con tematica de Halloween , que ese no era un criterio de evaluacion pero quise hacerlo con un diseño, desarrollado en PHP, utilizando sesiones para almacenar la lista de libros y alertas flotantes para notificaciones de usuario.

Funcionalidades:

Agregar libro

Formulario con campos: Titulo, Autor y Categoria

Alerta flotante de exito ✅ al agregar

Prestar libro:

Solo si esta disponible

Alerta flotante de exito ✅ si se presta o error ❌ si ya esta prestado

Devolver libro

Marca el libro como disponible

Alerta flotante de exito ✅

Eliminar libro

Quita libro de la lista

Alerta flotante de exito ✅

Busqueda de libros

Buscar por titulo, autor o categoria

Muestra alertas flotantes indicando si se encontraron resultados o no

Boton Ver todos para mostrar toda la lista nuevamente

Estilo / Diseño Halloween

Fondo animado: degradado negro → morado → naranja con efecto glow (halloweenGlow)

Tabla de libros: fondo oscuro semi-transparente, bordes redondeados, texto centrado

Botones: naranjas, efecto hover y ligera escala

Encabezado: texto amarillo-naranja con sombra brillante

Decoraciones: GIF de Halloween (calabaza) flotando

Imagen principal: tamaño reducido (150px)

Alertas flotantes

Ubicacion: esquina inferior derecha

Duracion: 5 segundos, desaparecen automaticamente

Tipos:

exito → verde

error → rojo

Icono 🎃 antes del mensaje
